# La P’tite Bulle

Landing page de La P’tite Bulle, une expérience P’tit Kiwi.

- **Écran 1** : la bulle s’éveille quand on tape son adresse, et le formulaire se fait en deux temps (adresse, puis e-mail).
- **Écran 2** : au défilement, la section se fige et le rouleau peint le nouveau site par-dessus l’ancien.
- **Avis et FAQ** : des panneaux qui s’ouvrent par-dessus la page.

Site statique en HTML, CSS et JavaScript, sans étape de construction. Les polices (Manrope, Bricolage Grotesque, Caveat, licence OFL) sont hébergées dans `fonts/`.

## À compléter

- Les trois avis clients dans le panneau Avis (`index.html`, recherchez « [Collez ici »).
- L’adresse e-mail de contact et, si besoin, une fourchette de prix dans la FAQ.
- Les liens « Voir les 30 avis sur Wix » et « CGV ».
- L’envoi réel du formulaire : il est simulé pour l’instant (aucune donnée n’est envoyée).

## Mise en ligne

Hébergé sur Vercel : chaque `git push` sur `main` met le site à jour.
